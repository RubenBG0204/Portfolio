01 / RESUMEN

Una aplicación web sobre una base de datos NoSQL.

Es un proyecto que realicé durante el primer año del ciclo de grado superior para trabajar con MongoDB. La aplicación importa los 151 primeros Pokémon desde PokéAPI y los guarda en MongoDB Atlas.

Desde la interfaz web se pueden consultar, crear, editar y borrar, filtrarlos con consultas de MongoDB y ver estadísticas calculadas con el aggregation framework. El repositorio separa la configuración, los controladores, los modelos y las rutas. Se ejecuta en local y no hay demo desplegada.

En el desarrollo utilicé Claude (Anthropic) como asistente de inteligencia artificial, con el objetivo de ver cómo se trabaja con IA en un proyecto real y qué tal nos desenvolvíamos juntos.

02 / FUNCIONES EN EL REPOSITORIO

De la importación a las estadísticas.

  • Importación: un script carga los 151 primeros Pokémon desde PokéAPI en la base de datos.
  • CRUD completo: crear, consultar, editar y borrar Pokémon desde la aplicación.
  • Filtros avanzados: consultas con MongoDB para acotar el listado.
  • Estadísticas: resultados calculados con el aggregation framework.
  • Detalle: vista de cada Pokémon con sus estadísticas completas.
  • Ejecución en Windows: archivos .bat para importar los datos, arrancar la aplicación y probar la conexión.

03 / EJECUCIÓN EN LOCAL

Cómo probarlo en tu equipo.

  • Entorno: crear un entorno virtual de Python e instalar las dependencias de requirements.txt.
  • Configuración: copiar .env.example como .env y completar MONGO_URI con la conexión de MongoDB Atlas.
  • Datos: ejecutar scripts/import_pokemon.py para importar los Pokémon.
  • Aplicación: ejecutar app.py y abrir http://127.0.0.1:5000.
