01 / RESUMEN

Una tienda multipágina con backend en Laravel.

Sigilious nació como el proyecto de una marca de ropa creada junto a un amigo. Tenía el frontend completo (inicio, tienda, ficha de producto, carrito, checkout, perfil, registro, acceso, pedidos, contacto y administración) y lo he migrado a un proyecto Laravel con MySQL, sustituyendo el backend anterior en Supabase.

El JavaScript modular sigue gestionando la interfaz y ahora habla con una API propia: productos, cuentas, carrito, pedidos y administración se guardan en MySQL. El estado sigue siendo de desarrollo y no hay demo desplegada.

02 / FUNCIONES EN EL REPOSITORIO

Del catálogo a la administración.

  • Tienda: búsqueda, categoría (con accesos directos desde la página principal), rango de precio y ordenación.
  • Productos: ficha con tallas y cantidad; el catálogo se lee de MySQL a través de una API de Laravel.
  • Carrito: se guarda en MySQL por usuario y reaparece al iniciar sesión desde otro navegador; sin sesión usa almacenamiento local.
  • Cuentas: registro, inicio y cierre de sesión con tokens de Laravel Sanctum.
  • Pedidos: se guardan en MySQL y el servidor calcula el total a partir de los precios de la base de datos, sin fiarse del cliente.
  • Administración: alta, edición y borrado de productos, solo para usuarios con permiso de administrador mediante un middleware.
  • Datos: migraciones y un seeder con los productos de ejemplo.

03 / PUNTOS A REVISAR

Qué falta antes de publicar.

  • Checkout: valida un número de tarjeta y confirma el pedido, pero no hay pasarela de pago; no debe presentarse como compra real ni usarse para cobrar.
  • Recuperación de contraseña: aún no está disponible, porque requiere configurar el envío de correos.
  • Contacto y newsletter: validan campos y muestran mensajes de éxito tras una espera, pero no envían datos a ningún servicio.
  • Tests: el proyecto no tiene todavía pruebas automáticas.
  • Despliegue: funciona en local; falta publicarlo en un servidor.
